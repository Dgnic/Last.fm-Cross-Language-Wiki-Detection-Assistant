Last.fm 跨语言维基跳转助手 Last.fm Cross-Language Wiki Redirect Helper

用 Ai 写的非常简单的小脚本，功能只有一个，就是当你在 Last.fm 上访问专辑或音乐人页面，当前语言无维基时，脚本将自动识别页面文本，并检测其余 11 种语言中是否存在相应的维基页面。若检测到存在，页面右下角将出现结果提示，并提供可跳转的链接。

该脚本最初仅为自用，但想到也许其他朋友也有类似的需求所以分享出来了。只不过由于是 Ai 写的，所以如果遇到什么 bug，作者可能无法提供修复。希望大家都能跨越语言的樊篱，自由地汲取知识。

A very simple script written with AI, which has only one function: when you visit an album or artist page on Last.fm and there is no Wikipedia in the current language, the script will automatically recognize the page text and check if there are corresponding Wikipedia pages in any of the other 11 languages. If found, a result prompt will appear in the lower right corner of the page, providing a clickable link.

This script was initially created for personal use, but I thought that perhaps other friends might have similar needs, so I decided to share it. However, since it was written by AI, if any bugs occur, the author may not be able to provide fixes. I hope everyone can cross the barriers of language and freely absorb knowledge.
