Last.fm 跨语言维基跳转助手 Last.fm Cross-Language Wiki Redirect Helper

用 Ai 写的非常简单的小脚本，功能只有一个，就是当你浏览 Last.fm 上的专辑或音乐人页面且当前语言没有维基内容时，脚本会自动检测文本并检查其他 11 种语言是否存在对应的维基页面。如果有的话，右下角会弹出结果，并给出可以跳转的链接。

一开始只是自用，但想到也许其他朋友也有类似的需求所以分享出来了。只不过由于是 Ai 写的，所以如果遇到什么 bug 的话我也不一定能修复。

A very simple script written with AI, which has only one function: when you browse an album or artist page on Last.fm and the current language does not have Wikipedia content, the script will automatically detect the text and check if there are corresponding Wikipedia pages in 11 other languages. If there are, a result will pop up in the bottom right corner along with a link to jump to it.

It was initially for personal use, but I thought maybe other friends might have similar needs, so I shared it. However, since it was written by AI, I may not be able to fix any bugs that arise.
